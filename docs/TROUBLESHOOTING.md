# Troubleshooting

## Pods pending
`kubectl -n mimir get pods -o wide` ; `kubectl -n mimir describe pod POD` ; `kubectl -n mimir get pvc`. Check StorageClass, quota, scheduling/taints and topology.

## Query has no data
A fresh Mimir has no samples. Check the upstream remote_write sender, gateway address, tenant header on BOTH writes and queries, time range, and HTTP response codes. `up` exists only if a producer has written it.

## Remote write failures
Verify `POST /api/v1/push` carries valid Snappy-compressed Prometheus remote_write protobuf. Verify TLS, gateway, tenant header, DNS and egress. A plain curl GET/POST does not test write success.

## MinIO lab fails
Check MinIO pod/PVC readiness and credentials generated by chart; consider StorageClass permissions, image pull errors and blocked policies.

## Ring / distributor / ingester errors
Check the component logs and gossip/memberlist networking. Check WAL disks and object-store availability. Do not delete PVCs to force recovery.

## Useful commands
```bash
helm status mimir -n mimir
kubectl get pods,pvc,svc -n mimir
kubectl get events -n mimir --sort-by=.lastTimestamp | tail -40
kubectl logs -n mimir deploy/mimir-distributor --tail=100
```
